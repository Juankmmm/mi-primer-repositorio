# Calculadora Interactiva en Node.js 🧮

Proyecto de una calculadora por consola desarrollada con **JavaScript** y **Node.js**.

## 🚀 Funcionalidades
* Operaciones básicas: Suma, Resta, Multiplicación y División.
* Manejo de errores (validación de división por cero).
* Lectura de datos dinámicos mediante consola.

## 🛠️ Tecnologías
* **Lenguaje:** JavaScript
* **Entorno de ejecución:** Node.js
* **Librerías:** `prompt-sync`
